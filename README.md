# 🏠 Rent Calculator

## About the Project
This is my first Python project as a Computer Science Engineering student.

This program calculates shared room expenses, including rent, food, electricity bills and cleaning costs.

## Features
- Total room rent
- Food expenses
- Electricity bill calculation
- Cleaning costs
- Number of people sharing the room
- Per-person expense calculation

## Technologies Used
- Python 3

## How to Run
1. Install Python.
2. Download this repository.
3. Open the folder in VS Code.
4. Run:

python rent_calculator.py
